Русский

Chart Runner не собирает, не хранит и не передаёт персональные данные. Приложение не требует аккаунта. Прогресс игры хранится только на вашем устройстве.

Для построения трасс приложение запрашивает публичные котировки у Binance API (api.binance.com) по HTTPS. Эти запросы не содержат идентификаторов пользователя или устройства. Аналитика, реклама и сторонние SDK отсутствуют.

Игра. Вся валюта в игре виртуальная. Не является финансовым советом.

English

Chart Runner does not collect, store, or share any personal data. No account is required. Game progress is stored only on your device.

To build tracks, the app requests public price data from the Binance API (api.binance.com) over HTTPS. These requests contain no user or device identifiers. There are no analytics, no ads, and no third-party SDKs.

This is a game. All in-game currency is virtual. Not financial advice.
