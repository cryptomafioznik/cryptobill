# CRYPTOBILL / CHART RUNNER — Visual V0 brief

Дата: 2026-07-31  
Статус: **PROTOTYPE / MANUAL_REVIEW_REQUIRED**  
Курс: **B — честный 2D+**

## Цель

Проверить в изолированном Canvas 2D-стенде две портретные подачи одного и того же бокового
героя: механически честную side-view сцену и среду с настоящим перспективным схождением.
Прототип не содержит физики, не читает и не пишет `localStorage`, не зависит от production loop
и не изменяет `toys/chartrider.html`.

## Арт-принципы

1. Герой, контакт колёс и ближайший профиль важнее неона и города.
2. Side-profile PNG не искажаются в ложный 3/4-ракурс.
3. В V0-A глубина живёт в атмосферной перспективе, слоях города, параллаксе, световой и
   контактной тени. Поверхность остаётся боковой.
4. В V0-B ширина поверхности действительно уменьшается к точке схода; дальние маркеры и
   интервалы также уменьшаются. Это отдельная гипотеза, а не доказательство совместимости с героем.
5. Collision-профиль в V0-A совпадает с верхней линией материала. В V0-B точка контакта героя
   является ближним швом, из которого начинается перспективная среда.
6. Неон показывает прогресс, полезную кромку и нажатое управление; он не заполняет фон.
7. За героем локально затемнён и успокоен фон. Дальний город мягче и менее контрастен ближнего.

## Палитра

| Роль | Цвет |
|---|---|
| Ночной верх | `#09091B` |
| Глубокая тень | `#03050F` |
| Материал трассы | `#15192C` / `#242840` |
| Нейтральный кант | `#B8CAE2` с низким bloom |
| Положительное действие / газ | `#6EFFCD` |
| Вес / предупреждение | `#FF7CA4` |
| Перспективный кандидат | `#FFAA70` |
| HUD-текст | `#E8EFFF` / `#8797BA` |

Белый/красный герой сохраняет максимальный локальный контраст. Голубой кант намеренно тонкий
и менее яркий, чем белые части байка и шлема.

## Композиция

- Hero anchor: 25% ширины; на подъёме допускается 28% для сохранения полного силуэта.
- Передняя часть героя оставляет около 55–60% кадра для чтения следующего препятствия.
- Видимая высота полного героя на 430×932: целевые 15–18%.
- Gameplay band: от верхней точки героя/следующего препятствия до нижней массы трассы,
  ориентир 38–45% высоты в технических состояниях.
- Верхняя треть занята HUD, атмосферой и масштабируемым городом, но не пустым однотонным небом.
- Нижний UI отделён тёмным градиентом и не перекрывает профиль или зону посадки.

## Целевые размеры

| Viewport | Назначение |
|---|---|
| 430×932 | основной standalone/full portrait |
| 430×791 | реальная видимая область Safari из референсного видео |
| 320×568 | нижняя функциональная граница iPhone SE |

Canvas работает в CSS-пикселях, backing store использует DPR с ограничением 2. Геометрия,
размер героя, HUD и touch-кнопки вычисляются от фактического viewport.

## HUD и touch UI

HUD показывает только прогресс, время, чекпоинт и паузу. Пауза — 56×56 CSS px.

Техническое управление:

- газ: три направленных шеврона;
- тормоз: колодка/диск;
- вес назад: силуэт байка + вращательная стрелка;
- вес вперёд: зеркальная вращательная стрелка.

Минимальная фактическая высота touch-target в стенде — 58 CSS px. Активное состояние меняет
не только цвет, но и яркость/заливку. PUMP, прыжок, деньги, плечо, ликвидация и endless-рекорды
отсутствуют.

## Использованные ассеты

Все исходники существовали до Visual V0 и не изменялись:

- `toys/assets/trials25d/bg_far_sky_chart.png` — дальний sky/chart слой;
- `toys/assets/trials25d/city_mid_rgba.png` — мягкий средний слой города;
- `toys/assets/trials25d/foreground_palms_rgba.png` — приглушённый силуэтный слой.

Новые bitmap-ассеты и ImageGen-материалы не создавались. Остальная графика — процедурный
Canvas: дополнительный skyline, market-line, дымка, road geometry, тени, HUD и кнопки.

## Ограничения

- Только Canvas 2D; без WebGL, Three.js и 3D-моделей.
- Стенд показывает фиксированные состояния, а не симуляцию.
- Визуальная дорога не меняет и не импортирует production collision line.
- Production-файлы, физика, `FnDrive`, `PHX`, timing, touch logic и production HUD не меняются.
- `docs/current-25d-handoff.md` остаётся неизменным до выбора пользователя.
- Ни один вариант не считается принятым до ручного решения пользователя.

## Запуск и сравнение

```text
python3 -m http.server 4174
http://localhost:4174/toys/visual-v0.html
```

Прямые варианты:

```text
?variant=sideplus&state=flat
?variant=perspective&state=air
```

Состояния: `flat`, `climb`, `air`, `compression`. Клавиши: `A`/`B` — вариант, `1`…`4` —
состояние. `clean=1` скрывает только лабораторный переключатель; игровой HUD и touch-макет остаются.
