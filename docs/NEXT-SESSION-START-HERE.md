## КАК СОБИРАТЬ И ПРОВЕРЯТЬ

```bash
tools/unity-build-mac.sh                      # честная сборка: падает на лицензии/компиляции/старом бинаре
cd unity && build/mac/ChartRunner.app/Contents/MacOS/ChartRunner -screen-width 430 -screen-height 932 -screen-fullscreen 0 -shots    # кадры заезда
... -shotsUi                                  # кадры экранов howto/title/setup/garage/settings/dead
tools/ios-deploy.sh                           # на телефон (телефон разблокирован!)
```
Гейты: EditMode 8/8; PlayMode `-testFilter "ChartRunner.Tests.WaveGate|ChartRunner.Tests.AcceptanceBattery"`
→ 10/11 (падает только H_RecoveryWindow — известное открытое решение про окно восстановления).
Полный PlayMode-набор содержит многоминутные развёртки — не гонять целиком.

**Лицензия Unity Personal живёт офлайн ограниченно.** Если сборка молча не идёт —
Unity Hub разлогинен; входит пользователь, я не могу.

## ЛОВУШКИ, ОПЛАЧЕННЫЕ ЭТОЙ СЕССИЕЙ

- Ось Y исходника вниз; градиенты Canvas в sRGB; статические инициализаторы C# по порядку.
- Дистанция исходника — **браузерные метры = px/10** (`dist=floor(bike.x/10)`), все
  константы волны/DCA/миссий в них. Реальные метры = ×0.283.
- Линия езды — **середина** деки (TDECK/2 вверх и вниз), линия данных по дальней кромке.
- `BikeState` публикуется после первого шага физики — на кадре создания нули; якорить на трансформ.
- Герой валидированной версии — 7.2 % высоты кадра; обзор 1.52 с. Мои 12 % были ошибкой.
