## ЧЕГО ЕЩЁ НЕТ ПРОТИВ САЙТА — по порядку релиза

1. **Эффекты апгрейдов в физике** (стр. 1509): eng → тяга ×(1+0.13·lvl), grip → µ ×(1+0.15·lvl)
   + конус посадки, susp → демпфер ×(1+0.22·lvl), air → воздушный наклон ×(1+0.18·lvl).
   Сейчас куплены — не работают. **Первым делом.**
2. **Байки и скины** (экран `bikes`, 7 байков, 3 скина): спрайты выгоняются из браузера
   `DPR=4; bikeSprites(BIKES[i])` (см. память `port-validated-look-dont-invent`), физика —
   `accel/grip` из `Economy.Bikes`.
3. **События** rally/whale/flash (стр. 139, resolveEvent стр. 1859) — генерация участков
   и выплаты. Баннеры уже были в CandleTrackGenerator, в ticker-режим не подключены.
4. **Путь трейдера** (CHALLENGES стр. 914, медали, reqRank) + экран `path`.
5. **Дейли «Рынок сегодня»** (стр. 377+): трасса дня, 3 попытки, стрик.
6. Флипы/трюки (b155/b158) — их нет и в физике Unity; миссии «сальто» и онбординг-пункты
   про флипы пропущены.
7. Экран смерти: кнопки ШЕР/КЛИП не переносятся (браузерные API).
8. Релиз: иконка, launch screen, App Store метаданные, отключить Development-флаги (уже).

## ЛОВУШКИ, ОПЛАЧЕННЫЕ ЭТОЙ СЕССИЕЙ

- Ось Y исходника вниз; градиенты Canvas в sRGB; статические инициализаторы C# по порядку.
- Дистанция исходника — **браузерные метры = px/10** (`dist=floor(bike.x/10)`), все
  константы волны/DCA/миссий в них. Реальные метры = ×0.283.
- Линия езды — **середина** деки (TDECK/2 вверх и вниз), линия данных по дальней кромке.
- `BikeState` публикуется после первого шага физики — на кадре создания нули; якорить на трансформ.
- Герой валидированной версии — 7.2 % высоты кадра; обзор 1.52 с. Мои 12 % были ошибкой.
